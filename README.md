## 📋 Overview

**MediCore Pharmacy ERP** is a commercial-grade, enterprise-ready pharmacy management system designed for hospitals, clinics, and retail pharmacies. Built with modern SaaS architecture, it provides a comprehensive solution for medicine inventory management, point-of-sale operations, customer management, and advanced analytics.

### ✨ Key Features

| Feature | Description |
|---------|-------------|
| 🏥 **Executive Dashboard** | Real-time KPIs, revenue charts, and performance analytics |
| 💊 **Medicine Management** | Complete CRUD operations with 20+ pre-loaded medicines |
| 📦 **Inventory Intelligence** | Smart stock monitoring with critical alerts |
| 🛒 **POS System** | Professional retail pharmacy checkout with cart management |
| 👥 **Customer Management** | Patient records, purchase history, loyalty tracking |
| 🚚 **Supplier Management** | Vendor directory and order tracking |
| 📊 **Reports & Analytics** | Interactive charts for sales and inventory analysis |
| 🤖 **AI Assistant** | Smart restock recommendations and demand insights |
| 🌓 **Dark/Light Mode** | Premium theme switching with persistence |
